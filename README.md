# Крепко - Универсальное мобильное приложение для строительных задач

## О проекте

Мобильное приложение «Крепко» разработано для автоматизации процессов консультирования клиентов магазина строительных материалов, предоставления инструментов для выполнения инженерных и строительных расчетов, а также упрощения подбора необходимых материалов и крепежных изделий.

Приложение предназначено для сотрудников магазина «Крепко» и его клиентов, позволяя быстро получать необходимую информацию, выполнять расчеты и подбирать оптимальные материалы без обращения к бумажным каталогам или консультантам.

## Функциональные возможности

### 1. Конвертер единиц измерения
- Поддержка 6 основных категорий: геометрические, механические, временные, энергетические, строительные, экономические
- 24 подкатегории единиц измерения
- Более 150 различных единиц измерения
- Мгновенная конвертация в обе стороны
- Интуитивно понятный интерфейс с выпадающими списками

### 2. Калькулятор
**Инженерный режим:**
- Арифметические операции (+, -, *, /)
- Возведение в степень (x², x³, x^y)
- Извлечение корней (√, ∛)
- Логарифмические функции (log, ln)
- Тригонометрические функции (sin, cos, tan) с переключением DEG/RAD

**Финансовый режим** (в разработке)
**Строительный режим** (в разработке)

### 3. Опросники подбора материалов
Интерактивная система подбора оптимальных материалов на основе ответов пользователя:

- **Подбор крепежа** - в зависимости от материала основания, веса нагрузки и иных факторов
- **Подбор утеплителя** - в зависимости от конструкции и материала основания
- **Подбор покрытия (пол)** - в зависимости от проходимости, условий, приоритетов, нагрузки
- **Подбор покрытия (кровля)** - в зависимости от типа крыши, климата, приоритетов
- **Выбор герметика** - в зависимости от вида, типа поверхности, приоритетов, условий
- **Выбор краски** - в зависимости от требований, типа поверхности, приоритетов, условий

## Установка и запуск

### Системные требования
- Android 6.0 (API 23) и выше
- Свободное место: 50 МБ
- Доступ к интернету (для обновлений)

### Установка из APK
1. Скачайте APK-файл приложения с официального сайта магазина «Крепко»
2. Разрешите установку из неизвестных источников в настройках телефона
3. Откройте скачанный файл и следуйте инструкциям
4. После установки нажмите «Открыть»
